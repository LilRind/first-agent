# Spec Delta

## Purpose

一个由 LLM 驱动的 ReAct 旅行助手，能按 Thought-Action-Observation 循环，通过天气查询与景点推荐两个工具，分步解决"查天气→荐景点"类用户请求，并支持离线 mock 演示。

## ADDED Requirements

### Requirement: ReAct 循环求解

系统 MUST 对一个用户请求运行 ReAct 主循环：每轮把包含系统说明书、用户请求和全部历史的对话发给 LLM，解析其输出；当输出为工具调用则执行并把观测结果回喂给下一轮；当输出为 `Finish[答案]` 则以该答案结束；循环 MUST 有轮数上限。

#### Scenario: 依次调用工具后以 Finish 收尾
- **WHEN** 用户请求"帮我查北京天气并推荐景点"，LLM 首轮输出调用 `get_weather`、次轮调用 `get_attraction`、末轮输出 `Finish[...]`
- **THEN** 系统依次执行两个工具、把各自观测结果纳入历史，最终返回 `Finish` 中的答案并终止

#### Scenario: 达到轮数上限仍未收尾
- **WHEN** 连续多轮 LLM 均未输出 `Finish`，轮数到达上限
- **THEN** 系统停止迭代并返回一条兜底提示，说明未能得出最终答案

### Requirement: 工具调用与派发

系统 MUST 能把 LLM 的 Action 解析为"调用某工具 + 具名参数"，按工具名从已注册工具中查找并执行，返回自然语言结果；对不存在的工具 MUST 提示并引导重试。

#### Scenario: 解析并执行工具调用
- **WHEN** LLM 输出 `Action: get_weather(city="北京")`
- **THEN** 系统解析出工具名 `get_weather` 与参数 `city=北京`，执行该工具并把结果以观测形式回喂

#### Scenario: 未知工具引导重试
- **WHEN** LLM 调用一个未注册的工具名
- **THEN** 系统不崩溃，提示该工具不存在并要求 LLM 换一个工具重新输出

### Requirement: 天气查询工具

系统 MUST 提供一个天气工具：给定城市名，查询实时天气，返回形如"`{城市}当前天气:{描述}，气温{温度}摄氏度"的自然语言句子；城市无效或网络异常时 MUST 返回错误说明而非抛出异常。

#### Scenario: 有效城市返回天气句
- **WHEN** 调用天气工具并传入有效城市名（如 北京）
- **THEN** 返回包含城市名、天气描述与气温的完整句子

#### Scenario: 无效城市或网络异常
- **WHEN** 传入的城市名无法解析，或请求天气服务时出现网络错误
- **THEN** 返回以"错误:"开头的说明，且不中断整个智能体

### Requirement: 景点推荐工具

系统 MUST 提供一个景点推荐工具：给定城市与天气状况，搜索并返回景点推荐；未配置搜索 API 密钥或搜索失败时 MUST 返回错误说明。

#### Scenario: 配置密钥且搜索成功
- **WHEN** 调用景点推荐工具并传入有效城市与天气，且已配置搜索 API 密钥
- **THEN** 返回基于搜索结果的景点推荐文字（优先综合回答，其次按条列出结果）

#### Scenario: 未配置密钥
- **WHEN** 调用景点推荐工具但未配置搜索 API 密钥
- **THEN** 返回提示未配置密钥的错误说明，不崩溃

### Requirement: LLM 对话客户端

系统 MUST 能通过一个 OpenAI 兼容接口调用任意 LLM 服务：以多轮对话消息列表作为输入，返回模型的纯文本回复；未配置 API 密钥时 MUST 明确报错而非静默失败。

#### Scenario: 正常返回模型回复
- **WHEN** 已配置 OpenAI 兼容接口的 key/地址/模型，并提交含 system 与 user 的消息列表
- **THEN** 返回该消息列表对应的模型纯文本回复

#### Scenario: 未配置密钥
- **WHEN** 未配置 LLM API 密钥却调用真实客户端
- **THEN** 明确抛出"未配置密钥"的错误，提示可改用离线 mock 模式

### Requirement: 离线 mock 模式

系统 MUST 提供不依赖网络与 API 密钥的离线演示模式：以一组预设 LLM 回复驱动循环，使"查天气→荐景点→Finish"的完整流程可在本地复现。

#### Scenario: 离线跑通完整流程
- **WHEN** 以 mock 模式运行，预设回复依次为调用天气、调用景点、Finish
- **THEN** 系统按预设顺序执行两个工具并以预设的 Finish 答案结束，全程不发起真实网络调用
